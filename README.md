# DSA-LeetCode

Welcome to my DSA Journey.

This repository contains my solutions to Data Structures and Algorithms problems that I solve while preparing for Software Engineering internships and technical interviews.

My focus is not just on solving problems, but on understanding the underlying patterns, improving my problem-solving approach, and writing clean and efficient C++ solutions.

## My Goals

- Build strong DSA fundamentals
- Improve logical and problem-solving skills
- Understand common DSA patterns
- Write optimized and readable C++ code
- Learn from mistakes and edge cases
- Prepare for technical interviews
- Maintain consistency in problem solving

## Problem Solving Approach

For each problem, I try to follow:

**Understand → Analyze → Brute Force → Optimize → Identify Pattern → Code → Analyze Complexity → Learn**

I also document important mistakes and observations so that I can improve my approach instead of simply memorizing solutions.
