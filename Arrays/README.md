## My Approach

For each problem, I try to:

1. Understand the problem and constraints
2. Think about the brute-force solution
3. Identify the bottleneck
4. Find the appropriate DSA pattern
5. Optimize the solution
6. Analyze time and space complexity
7. Implement the solution in C++
8. Note down important learnings and mistakes

## Key Learnings

### Prefix Sum

Useful when we need to efficiently calculate or compare sums of different portions of an array.

### Hashing

Useful when we need fast lookup, frequency counting, or need to remember previously seen elements.

### Two Pointers

Useful for problems where two indices can be moved strategically to reduce unnecessary comparisons.

### Sliding Window

Useful for problems involving contiguous subarrays or subarrays satisfying a particular condition.
